## 简介

`mcp-go-x402` 是一个为 [MCP-Go](https://github.com/mark3labs/mcp-go) 客户端和服务器提供 x402 支付协议支持的库。该项目旨在实现自动化的链上支付处理，支持多种加密货币网络和资产类型。本贡献指南旨在为社区成员提供清晰的参与路径，包括代码贡献、文档改进、问题报告和功能建议等。

## 代码贡献流程

### 提交 Issue

在开始代码贡献之前，建议先通过提交 Issue 来讨论您的想法或报告问题。这有助于确保您的工作方向与项目目标一致。

- **Bug 报告**：请详细描述问题现象、复现步骤、预期行为和实际行为。如果可能，请附上相关日志或错误信息。
- **功能建议**：清晰地阐述您希望添加的功能、其用途以及对项目的价值。可以参考 `README.md` 中的 "Features" 部分来了解现有功能。
- **技术讨论**：对于架构变更或重大功能，建议先发起讨论，以获得社区反馈。

### 创建 Pull Request

1. **Fork 仓库**：在 GitHub 上 Fork `mcp-go-x402` 仓库到您的个人账户。
2. **创建分支**：基于 `main` 分支创建一个新分支，例如 `feature/new-payment-option` 或 `fix/bug-in-signer`。
3. **编写代码**：实现您的功能或修复。请确保代码遵循项目的风格规范。
4. **编写测试用例**：为您的代码添加单元测试。项目使用 `github.com/stretchr/testify` 作为测试框架，可以在 `client_options_test.go` 和 `signer_test.go` 等文件中找到测试用例的编写方式。
5. **提交更改**：提交您的代码更改，并编写清晰的提交信息。
6. **创建 PR**：在 GitHub 上创建 Pull Request，关联到您讨论的 Issue（如果有）。在 PR 描述中，详细说明您所做的更改、解决的问题以及任何需要注意的事项。

### 代码风格规范

- **Go 语言规范**：遵循 Go 语言的官方编码规范。
- **命名约定**：使用有意义的变量和函数名，遵循 Go 的驼峰命名法。
- **注释**：为复杂的逻辑添加注释，确保代码的可读性。
- **依赖管理**：通过 `go.mod` 文件管理依赖，避免引入不必要的第三方库。

## 开发环境搭建

### 技术栈

- **编程语言**：Go (版本 1.24.0)
- **依赖管理**：Go Modules
- **测试框架**：`github.com/stretchr/testify`
- **加密库**：`github.com/ethereum/go-ethereum` (用于钱包和签名功能)
- **BIP-39/BIP-32**：`github.com/tyler-smith/go-bip39` 和 `github.com/tyler-smith/go-bip32` (用于助记词和密钥派生)

### 依赖管理

项目的依赖由 `go.mod` 文件管理。您可以通过以下命令来安装和更新依赖：

```bash
go mod tidy
```

这将自动下载 `go.mod` 文件中声明的所有依赖项，并清理未使用的依赖。

### 快速开始

1. **克隆仓库**：
   ```bash
   git clone https://github.com/mark3labs/mcp-go-x402.git
   cd mcp-go-x402
   ```

2. **安装依赖**：
   ```bash
   go mod download
   ```

3. **运行测试**：
   ```bash
   go test ./...
   ```

4. **查看示例**：项目包含客户端和服务器的示例代码，位于 `examples/` 目录下，可以帮助您快速理解如何使用该库。

## 代码审查标准

为了确保贡献代码的质量，我们制定了以下审查标准：

- **功能完整性**：代码是否完整地实现了预期功能？
- **代码质量**：代码是否清晰、简洁、易于维护？是否遵循了项目的编码规范？
- **测试覆盖**：是否有足够的单元测试来验证代码的正确性？测试是否覆盖了边界情况？
- **文档更新**：如果功能有变化，是否相应地更新了 `README.md` 或其他文档？
- **向后兼容性**：更改是否破坏了现有 API？如果必须破坏，是否有充分的理由和迁移指南？
- **安全性**：代码是否存在潜在的安全风险，例如硬编码私钥或不安全的随机数生成？

## 社区行为准则

我们致力于营造一个积极、健康、包容的协作氛围。所有参与者都应遵守以下准则：
